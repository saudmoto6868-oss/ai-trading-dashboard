# دوران الفئات — Class rotation

> مصدر الحقائق: الكود (`modules/`) والمعمل الأسبوعي. صفحة **Lab Summary** (كانت تابات منفصلة: Class rotation).

- بيعد نتايج آخر مسح لـ Workspace حسب فئة الأصل (كريبتو، فوركس، معادن، مؤشرات، أسهم...): كام رمز فيه Setup، كام شراء وكام بيع، ومتوسط نتيجة الـ Setup كنسبة من أقصى نجوم، وأعلى رمز.

- ده وصف لحالة المسح دلوقتي (الماسح)، مش دليل ومش توقع. الفئات اللي مفيهاش بيانات حية للماسح (زي أسهم مصر والسعودية من Yahoo بحجم صفر، والأوبشن) غالبًا مش بتظهر.

- مفيش مسح جديد بيتعمل: بيقرا آخر نتيجة موجودة. لو لسه ما فيش نتيجة بيقولك افتح الـ Workspace وارجع.

- مكانه: صفحة **Lab Summary** ← قسم "دوران الفئات (آخر مسح)".
