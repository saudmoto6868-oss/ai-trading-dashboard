# الناقص — مرتب حسب الأولوية

## 1. تاب Order Flow Desk (أعلى أولوية)
الشات المخصص اللي هيجمع كل الأدوات: فوليوم بروفايل، فوت برينت، دلتا، فقاعات، DOM، ويكوف، آي سي تي. لسه مفيش كود — اتفقنا على الاسم والأدوات بس.

## 2. الأدوات الناقصة جوه الداشبورد
- جي إكس بأجزائه: جاما فليب، كول وول، بوت وول
- أوبشن فلو
- بوك ماب كأداة مستقلة (مش بس خيار لون)
- سيجنال ريجيم من إف آر إي دي

## 3. ربط شات جي بي تي
الحساب لسه مش معمول. إكس بيكس يقدر يتعامل معاه من جوه المشروع لما يتعمل.

## 4. مشكلة صلاحية البايبلاين
إكس بيكس بلّغ عنها — التنفيذ واقف. خطوات الحل محفوظة في المحضر: Variables، Runners، Protected Branches.

## 5. اختبار الستاتبس الخمسة على بيانات حية
لسه ورق. محتاج باكتيست حقيقي قبل أي تنفيذ.

## 6. دمج الأدوات المفتوحة المصدر
- Freqtrade — سكيلز ومؤشرات وباكتيست وإم سي بي
- VectorBT MCP Server — تسع وثلاثين أداة
- smc-icm-trading — ستاشر موديل دخول
- pyvsmc — مكتبة نومباي بولارس
- smart-money-concepts — تايب سكريبت
- daily_stock_analysis — تحليل أسهم يومي على ست أسواق
- ClawStreet — سكيل تداول لأوبن كلاو وهرميس
