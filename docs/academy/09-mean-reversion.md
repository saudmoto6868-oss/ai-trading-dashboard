# Mean Reversion — فرع الأكاديمية

**الدور:** نظام **منفصل** للنطاق — لا يُخلط عشوائياً مع الترند.

## الفروع
RSI قصير · بولينجر · VWAP · فشلة كسر نطاق

## فلتر
ADX منخفض / نطاق واضح — وإلا تعطيل

## سيتب صعودي
تمدد لأسفل فوق دعم نطاق → RSI تشبع → دخول عكس → وقف تحت القاع → هدف وسط النطاق / VWAP
