# Streamlit iframe API migration — 2026-11-12

Status: proposed in MR !65; not merged.

The project pins Streamlit 1.66.0. The deprecated `components.html()` API was replaced with `st.iframe()` in:
- `modules/workspace.py`
- `modules/header_bar.py`
- `modules/tv_widget.py`
- `main.py` (QuantStats report)

These are JavaScript-based HTML documents, so an iframe is required. `st.html()` is not a drop-in replacement for the interactive pages. Fixed iframe heights are preserved and accessible descriptions are supplied.

The HTML is generated by trusted application code; no user-provided or LLM-generated HTML is passed to the iframe.

Validation: `tests/test_streamlit_iframe_migration.py` checks that no `components.html()` calls remain and compiles each migrated Python file. The required `streamlit_iframe_migration` job passed on pipeline 536.
