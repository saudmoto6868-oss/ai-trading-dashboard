# دليل العرض البصري — أكاديمية 6868 X

يُستخدم عند بناء تبويب Academy أو صفحات الشرح.

## لوحة الألوان

| معنى | لون مقترح | استخدام |
|------|-----------|--------|
| صعود / Long | `#22c55e` أخضر | أسهم صعود، مناطق شراء |
| هبوط / Short | `#ef4444` أحمر | أسهم هبوط، مناطق بيع |
| سياق / محايد | `#94a3b8` رمادي-أزرق | خطوط هيكل، ملاحظات |
| تأكيد | `#38bdf8` سماوي | شارات «تأكيد» |
| إبطال / خطر | `#f97316` برتقالي | خط الإبطال، تحذير |
| PRZ / منطقة حاسمة | `#a855f7` بنفسجي (شفاف) | صندوق PRZ أو زاوية |
| خلفية بطاقة | `#0f172a` / `#1e293b` | بطاقات الدرس |

## مكوّنات العرض (كل فكرة)

1. **عنوان + شارة الدور** (Primary / Context / Gate)  
2. **رسم mermaid أو ASCII كبير** للشكل  
3. **بطاقة خطوات 1→2→3→4** (سياق → دخول → وقف → هدف)  
4. **عمودان:** صعودي | هبوطي  
5. **صندوق إبطال** برتقالي  
6. **مثال رقمي** في بطاقة منفصلة  
7. **«في الرادار»** سطر واحد: هل يؤثر على Grade؟

## تأثيرات مقترحة في الواجهة (لاحقاً)

- ظهور تدريجي لخطوات السيتب (stagger)  
- نبض خفيف على منطقة PRZ أو مستوى الدخول  
- تبديل Tab: صعودي / هبوطي بنفس الرسم مع عكس الألوان  
- زر «أظهر الإبطال» يبرز الخط البرتقالي  
- وضع ليلي افتراضي متوافق مع الداشبورد
