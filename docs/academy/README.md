## خلاصة أدلة الباك تست (خارجي)

1. **Trend / TSMOM** — أقوى دليل مؤسسي/أكاديمي نسبياً (يومي؛ تكاليف تقتل السكالب)  
2. **Mean reversion** — قوي داخل نطاق؛ يُجمع مع الترند كمحفظة لا كإشارة واحدة  
3. **Levels** — متوسط؛ تعريف صارم  
4. **Sweep/sessions** — edge صغير ممكن؛ نسب التسويق مبالغ  
5. **SMC ميكانيكي** — هامشي (PF~1.2–1.5) لا سحري  
6. **OF** — بوابة لا نظام وحيد  
7. **Elliott/Gann/Harmonic** — ضعيف كنظرية كاملة قابلة للأتمتة
