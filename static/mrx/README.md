# Mr X - the real presenter (files go here)

The guide shows these files instead of the drawn presenter as soon as they exist (served by Streamlit static serving,
`.streamlit/config.toml` -> `enableStaticServing = true`, URL `/app/static/mrx/...`):

| file | what | spec |
|---|---|---|
| `idle.mp4` | standing, small natural movement, mouth closed | portrait 9:16 (720x1280), H.264 MP4, 5-10 s seamless loop, no sound, < 5 MB |
| `talk.mp4` | the same man talking with light hand gestures | same spec, same framing as idle |
| `photo.jpg` | optional: only a still photo (used when there are no videos) | portrait 9:16, >= 720x1280 |

Dark studio background, head to knees or full body, centred, soft key light. The edges fade out on the stage.
Only use a person you have the rights to (yourself / someone who agreed / an AI-generated person / a licensed avatar),
never a real person's photo taken from the internet.
