# طلب لفريق Claude Code (على الماك) — جروب تليجرام "XPiX" للتحكم في المنصة (2026-11-05، أمر المالك)

> كتبه حساب المراجعة (Claude، سحابي). الفريق على الماك عنده وصول للريبو وللمنصة والمتصفح؛ حساب المراجعة ما عندوش. اقرأ `docs/AGENT_PROMPT.md` و`docs/MEETING_ROOM.md` الأول.

## الهدف (كلام المالك)
جروب تليجرام اسمه **XPiX** (غير جروب Hermes). المالك يكتب فيه طلب بالعربي، والبوت:
1. **يسحب من المنصة:** لقطة شاشة للشارت/الأوردر فلو/الـDOM/التايم آند سيلز/الليميت تراكر، الإشارات، التنبيهات، الجورنال، المؤشرات، ويشرح "الدنيا إيه" وتحليل اليوم.
2. **يتحكم في المنصة:** يفتح/يقفل بانلز، يغيّر الرمز والفريم، يشغّل/يطفّي مؤشرات، **يرسم** على الشارت (خطوط، مستويات، مناطق)، ويبعت لقطة بعد التنفيذ.
3. يحلل صفقات، ويرد نص (وصوت/صور لاحقًا).

## قواعد ثابتة (من قواعد المشروع، ما تتخطّاهاش)
- **يرد على chat id بتاع المالك بس.** أي شات تاني يتجاهله.
- **من غير تنفيذ صفقات ولا أوامر شراء/بيع.** المنصة بتحلل وترسم بس.
- **مفيش مفاتيح/توكن في الكود ولا في الشات.** كله في env / Secrets.
- **ممنوع** لمس حساب TradingView الشخصي أو MT5/Exness أو أي بيانات دخول للمالك.
- ميزانية التوكنز: ردود متخزّنة، أصغر نموذج يكفي، سقف يومي. Gemini هو المخ حسب قاعدة المالك (`GEMINI_API_KEY`)؛ Claude بس لو `GUIDE_PROVIDER=claude`.
- أمانة: "mock-tested only" لو ما اتجرّبش حي، "n<30 مش دليل"، وما تخترعش أسعار.
- الدمج بأمر المالك بس ("ادمج N")، شغل على فروع وPRs.

## المعمارية المقترحة
```
تليجرام (جروب XPiX) ── بوت (على الماك، long-polling) ──► LLM (Gemini)
                                   │
                                   ├─ قراءة: modules/* (signal_log, alerts, lab, regime) + بيانات OKX/HL
                                   └─ تحكم: متصفح Playwright على الماك فاتح المنصة ──► window.XCMD (طبقة أوامر داخل التطبيق)
```
- المنصة (`modules/workspace_app.html`، جوه iframe في Streamlit) ما فيهاش واجهة أوامر خارجية دلوقتي. **الخطوة الأولى:** إضافة `window.XCMD` في `modules/ws/` (مش في الملف المولَّد، شوف `docs/WORKSPACE_PARTS.md`) بأوامر صغيرة وآمنة:
  `state()` (الرمز/الفريم/البانلز/المؤشرات)، `setSymbol(s)`, `setTf(tf)`, `addPanel(type)`, `closePanel(id)`, `toggle(indicatorId, on)`, `draw({kind:"hline"|"trend"|"zone", points:[...], label})`, `clearDrawings()`, `shot()` (يرجّع صورة).
- البوت يفتح المنصة في Chromium (Playwright/CDP) على الماك، يدخل على الـiframe، ويستدعي `XCMD`، ويصوّر.
- **قيد معروف:** الرسومات والإعدادات بتتحفظ في localStorage لمتصفح الماك ده. اللي يتعمل بالبوت يظهر في نفس المتصفح بس، مش على موبايل المالك إلا لو اتحفظت على السيرفر (قرار منفصل).
- الأوردر فلو/DOM/T&S بتتحسب جوه المتصفح من websockets حية: لقطة الشاشة هي أضمن طريقة تتشاف زي ما المالك بيشوفها.

## مراحل مقترحة (كل مرحلة PR + اختبار)
1. `XCMD` داخل التطبيق + اختبار Playwright بشموع mock (يمكن لحساب المراجعة يبنيها من السحابة؛ قوله لو عايزها).
2. بوت نصي: `/today SYMBOL`، `/shot SYMBOL TF`، `/signals`، `/alerts` + قفل chat id.
3. أوامر التحكم: افتح/اقفل/رسم، ولقطة بعد كل أمر.
4. صوت (Gemini TTS) وصور مولدة من الشارت. فيديو: أنيميشن شموع بـffmpeg فقط.

## تعديل بأمر المالك (2026-11-05): المخ = Claude Code على الماك، مش Gemini
- **المخ:** Claude Code (فريق الماك) بنموذج حسب المطلوب: Sonnet للأسئلة والتحليل السريع، Opus/أقوى للتحليل العميق وكتابة الكود. قاعدة "Gemini بس" كانت لميزات **التطبيق المنشور** (Guide وغيره)؛ دي طبقة المالك الشخصية على جهازه، فمش بتتعارض.
- **البوت = قناة بس:** جروب XPiX ←→ جلسة Claude Code على الماك. البوت بيمرّر رسالة المالك كمهمة لـClaude Code، وبيرجّع الرد والصور. مفيش مفتاح LLM داخل البوت.
- **Claude Code يشتغل بـ:** `XCMD` (تحكم ولقطات المنصة)، وقراءة الريبو (`signal_log`, alerts, lab, regime)، وبيانات OKX/HL العامة، ورسم الشارتس PNG.
- **دور حساب المراجعة (السحابي):** مدير المشروع: يكتب المهام والـbriefs، يراجع الـPRs، يفحص بالـmock، ويدمج بأمر المالك. التنفيذ الحي (تليجرام، المتصفح، الماك) عند فريق الماك.
- **قواعد ما اتغيّرتش:** يرد على chat id المالك بس؛ قراءة وعرض ورسم فقط، من غير أي أمر صفقة؛ مفيش مفاتيح في الشات أو الكود؛ ميزانية: اختار أصغر نموذج يكفي كل مهمة، وما يعيدش تحليل نفس الرمز/الفريم في نفس الساعة (خزّن الرد)؛ "mock-tested only" و"n<30 مش دليل" في كل رد تحليلي.
- **صلاحيات Claude Code على الماك:** يشتغل في مجلد المشروع بس، وصلاحيات الشيل بتتحدد بإعداداتك (permissions)؛ ما يلمسش بيانات الدخول أو حساب TradingView الشخصي أو MT5.
