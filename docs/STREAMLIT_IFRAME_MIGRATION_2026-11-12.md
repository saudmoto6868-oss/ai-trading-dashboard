# Streamlit iframe API migration — 2026-11-12

The project pins Streamlit 1.66.0. The deprecated `components.html()` API was replaced with `st.iframe()` in:
- `modules/workspace.py`
- `modules/header_bar.py`
- `modules/tv_widget.py`
- `main.py` (QuantStats report)

These are JavaScript-based HTML documents, so an iframe is required. `st.html()` is not a drop-in replacement for the interactive pages. Fixed iframe heights are preserved and accessible descriptions are supplied. Streamlit 1.66.0 has no `scrolling` argument on `st.iframe`: the header and workspace documents already set `html,body{overflow:hidden}`, the TradingView embed now adds the same containment, and QuantStats intentionally remains scrollable.

The HTML is generated by trusted application code; no user-provided or LLM-generated HTML is passed to the iframe.

Regression-check scope: `tests/test_streamlit_iframe_migration.py` scans `main.py` and all Python files under `modules/` except `modules/v7_page.py` for `components.html(`, checks the twelve expected iframe modules, verifies the fixed-height overflow behavior, and compiles the four migrated Python files. `modules/v7_page.py` is separately migrated and guarded by the V7 integration branch. It does not scan scripts, tests, or non-Python files.
