## اللي اتعمل
1. **ويدجت Trade Classes** (`tclass`، المصدر `modules/ws/24b_tclass.js`): تختار النوع (سكالب 1H←15m←5m، داي 4H←1H←15m، سوينج 1W←1D←4H، بوزشن 1M←1W←1D) والهدف بالنقاط (تلقائي أو 50…1000). محرك "ارتداد دعم/مقاومة" + قياس الارتدادات اللي فاتت (walk-forward، الستوب الأول لو الشمعة لمست الاتنين) + قوة من 6. مدارس إليوت / ICT / كلاسيك = صفقات السكانر مقسمة حسب النوع. القوي (4/6+ وعند المنطقة) بيروح Alerts ← كارت الصفقة، Ready، Signals، الشريط، الجورنال.
2. **إصلاح تجميد قديم** في كارت الصفقة (`setupHtml`): حلقة رسم microtask أثناء تحميل سياق الأوردر بوك، ودايمًا مع رموز `Y:` / `FH:`.
3. **قايمة «+ ويدجت» جديدة** (`wMenuBtn` في `26_snap.js`): لون لكل مجموعة، خط أكبر، اختصار لكل ويدجت (TC، SC، DOM...)، علامة NEW؛ الـselect الأصلي مخفي وشغال (تخطيطات / اختبارات / XCMD). Trade Classes أول واحدة في «القرار».
