# مرجع أساسيات المؤسسات والمحترفين — التداول والمخاطر والتنفيذ

**الغرض:** مرجع شامل لأهم المواضيع التي تعتمدها البنوك الاستثمارية، صناديق التحوط، مكاتب الـ prop، وفرق التنفيذ المؤسسي — أعمق من «إشارة شارت».  
**التاريخ:** 2026-10-23  
**طبيعة الوثيقة:** تعريفات وأطر عمل وتعليم؛ ليست نصيحة استثمارية ولا ضمان ربح.

## 1) خريطة المكتب داخل البنك / الصندوق

| الطبقة | الاسم | ماذا تفعل |
|--------|--------|-----------|
| **Front Office** | تداول، مبيعات، هيكلة | قرارات السوق، تسعير للعملاء، تنفيذ |
| **Middle Office** | مخاطر، تأكيد، حدود | قياس التعرض، حدود VaR، توافق الصفقات |
| **Back Office** | تسوية، عمليات، تقارير | Settlement، حفظ، محاسبة |

**تدفق صفقة مبسّط:** فكرة/طلب عميل → تسعير/تحوط → تنفيذ → حجز (booking) → تأكيد → تسوية → تقرير مخاطر وP&amp;L.

---

## 2) أدوار اللاعبين (لا تخلطهم)

| الدور | الهدف الأساسي | ملاحظة |
|-------|----------------|--------|
| **Market maker / Flow desk** | توفير أسعار للعملاء وجني السبريد مع إدارة مخزون | بعد Volcker: التركيز على الوساطة لا الـ prop الحر في البنوك الأمريكية الكبرى |
| **Agency execution** | تنفيذ أمر العميل بأفضل تنفيذ ممكن بلا أخذ مخاطرة اتجاهية كبيرة | قياس بـ TCA |
| **Prop / hedge fund PM** | عائد على رأس مال الصندوق ضمن حدود | استراتيجيات اتجاهية، نسبية، macro، quant… |
| **Quant researcher** | إشارات، نماذج، اختبارات | نادراً ينفّذ يدوياً كل يوم |
| **Risk manager** | حدود، ضغط، نماذج رأس المال | مستقل نسبياً عن التداول |
| **Sales** | علاقة العملاء وتوجيه التدفق | ليس «متداول إشارات يوتيوب» |

## 3) هيكل السوق — Market Microstructure (عمود فقري مؤسسي)

**التعريف:** دراسة كيف تتحوّل الأوامر إلى أسعار وتخصيصات: دفتر الأوامر، السبريد، العمق، المنصات، الشفافية، وتكلفة التنفيذ.

### 3.1 أسئلة السوق الثلاثة

1. من يتداول؟  
2. بأي سعر؟  
3. بأي ترتيب/آلية مطابقة؟

### 3.2 مفاهيم إلزامية

| مفهوم | المعنى |
|--------|--------|
| **Bid / Ask / Spread** | أفضل شراء / أفضل بيع / الفرق = تكلفة عبور فورية تقريباً |
| **Depth** | كمية معلقة على مستويات السعر |
| **Liquidity** | القدرة على تنفيذ حجم معقول بأثر سعري مقبول |
| **Price impact** | تحرّك السعر بسبب طلبك (مؤقت + دائم أحياناً) |
| **Adverse selection** | الخوف أن الطرف المقابل أعلم منك → صانع السوق يوسّع السبريد |
| **Inventory risk** | صانع السوق يتراكم عنده مخزون غير مرغوب |
| **Fragmentation** | تعدد المنصات (lit، dark، ATS) |
| **Dark pool / block** | تنفيذ كبير بأقل كشف مسبق |
| **HFT / latency** | سرعة الوصول تؤثر على من يلتقط السيولة |

### 3.3 نماذج كلاسيكية يُشار إليها في التدريب الجاد

- **Glosten–Milgrom:** السبريد يعوّض عن المتداول المطلع.  
- **Kyle:** أثر المعلومات والحجم على السعر.  
- إدارة مخزون الصانع (inventory models).

### 3.4 لماذا يهم المحترف أكثر من «نمط شارت»؟

لأن **تكلفة التنفيذ وأثر الحجم** يأكلان alpha المزعوم — خصوصاً مع زيادة حجم الأمر.

---

## 4) أنواع الأوامر والسيولة

| نوع الأمر | الفكرة |
|-----------|--------|
| **Market** | تنفيذ فوري بأفضل سعر متاح — تدفع السبريد/الأثر |
| **Limit** | سعر محدد — قد لا يُنفَّذ |
| **Stop / stop-limit** | تفعيل بعد كسر مستوى (في بعض الأسواق قواعد مختلفة) |
| **Iceberg / hidden** | إخفاء جزء من الحجم |
| **Pegged / midpoint** | مرتبطة بنقطة مرجعية داخل السبريد |

**عدواني vs سلبي:** أمر يأخذ السيولة (aggressive) مقابل أمر يوفّرها (passive).

## 5) التنفيذ المؤسسي وTCA

### 5.1 مشكلة المؤسسة

الأمر كبير → لا يُرمى دفعة واحدة على الدفتر → يُقسَّم إلى child orders عبر الزمن والمنصات.

### 5.2 خوارزميات تنفيذ شائعة

| خوارزمية | الفكرة |
|----------|--------|
| **VWAP** | جدولة تتابع حجم اليوم التاريخي/الحي |
| **TWAP** | توزيع زمني منتظم |
| **Implementation Shortfall (IS)** | تقليل الفرق بين قرار نظري وتنفيذ فعلي |
| **POV / participation** | نسبة من حجم السوق |
| **Liquidity-seeking** | البحث عن سيولة في منصات متعددة |

### 5.3 Transaction Cost Analysis (TCA)

قياس جودة التنفيذ مقابل معايير:

- Arrival price  
- VWAP / TWAP  
- السبريد والأثر  
- توقيت اليوم  

**المبدأ:** أداء الاستراتيجية ≠ أداء التنفيذ؛ يُقاسان منفصلين في المكاتب الجادة.

### 5.4 Block trades

- **Risk trade:** الوسيط يشتري/يبيع الكتلة ويتحمّل المخاطرة.  
- **Agency:** يعمل الأمر على فترة مقابل عمولة.

## 6) المخاطر وحدود البنوك (قلب المؤسسة)

### 6.1 عائلات المخاطر

| عائلة | أمثلة |
|--------|--------|
| **Market risk** | تحرّك أسعار، معدلات، FX، سلع، تقلب |
| **Credit risk** | تخلف طرف |
| **Counterparty / CVA** | مشتقات OTC |
| **Liquidity risk** | صعوبة تسييل أو تمويل |
| **Operational risk** | أنظمة، أخطاء، احتيال |
| **Model risk** | النموذج خاطئ أو أُسيء استخدامه |

### 6.2 أدوات القياس الشائعة

| أداة | الفكرة |
|------|--------|
| **VaR** | خسارة لا يُتوقع تجاوزها بنسبة ثقة خلال أفق زمني (تحت فرضيات) |
| **Expected Shortfall (ES)** | متوسط الذيل أبعد من عتبة — أهم في أطر أحدث (مثل مناقشات FRTB) |
| **Stress testing** | سيناريوهات قاسية تاريخية أو افتراضية |
| **Greeks / DV01** | حساسية المشتقات وأسعار الفائدة |
| **Stop-loss desk limits** | قطع خسائر محققة على مستوى المتداول/المكتب |
| **Position / concentration limits** | سقف على اسم، قطاع، دولة |

### 6.3 واقع المكاتب (من أبحاث حدود VaR)

- الحدود تُخصَّص داخلياً بين مكاتب الأصول.  
- كثير من المكاتب تعمل **تحت** الحد معظم الوقت (هامش أمان).  
- الربحية المعدّلة بالمخاطر تؤثر على إعادة تخصيص الحدود بين الأصول.

### 6.4 Trading book vs Banking book

- **Trading book:** مراكز يُعاد تقييمها سوقياً (mark-to-market) — محل VaR السوقي.  
- **Banking book:** قروض واستثمارات أطول أجلاً — قواعد رأسمال مختلفة.

## 7) بناء المحفظة وعوامل العائد

### 7.1 أفكار أساسية

| مفهوم | المعنى |
|--------|--------|
| **Diversification** | مخاطر غير مشتركة قد تنخفض في المحفظة |
| **Beta / market exposure** | الحساسية للسوق العام |
| **Alpha** | عائد زائد بعد ضبط عوامل الخطر (تعريفات تختلف) |
| **Factor models** | تفسير العوائد بعوامل (سوق، حجم، قيمة، زخم، جودة…) |
| **Volatility targeting** | تحجيم المراكز لهدف تذبذب |
| **Risk parity / ERC** | مساهمة مخاطر متوازنة تقريباً |
| **Correlation breakdown** | في الأزمات قد ترتفع الارتباطات فتفشل التنويع |

### 7.2 سلسلة المنهج الكمي الشائعة

```
Alpha / إشارة
  → بناء محفظة (أوزان، قيود، تحييد عوامل)
    → تنفيذ (تكلفة، دوران)
      → محاسبة P&amp;L
        → رقابة مخاطر
```

المكاتب الجادة تفصل هذه الطبقات؛ لا تخلط «إشارة الشارت» مع «حجم المحفظة» عشوائياً.

## 8) البحث المنهجي (ما يفعله الـ quant desk)

| مرحلة | محتوى |
|--------|--------|
| فرضية | لماذا يوجد عدم تسعير أو premia؟ |
| بيانات | نظافة، تواتر، انحياز بقاء، تكاليف |
| اختبار | out-of-sample، حساسية، انزلاق |
| مقاييس | Sharpe، Sortino، MaxDD، turnover، capacity |
| إنتاج | كود مستقر، رقابة، إيقاف تلقائي |

**مهارات تُذكر كثيراً:** إحصاء واحتمال، سلاسل زمنية، تحسين محافظ، Python للبحث، أحياناً C++/Rust للإنتاج منخفض الكمون.

## 9) المشتقات والتحوط — الحد الأدنى المؤسسي

| أداة | استخدام أساسي |
|------|----------------|
| **Futures / forwards** | تعرض أو تحوط اتجاهي/سعري |
| **Options** | لاخطية، تحوط ذيل، تداول تقلب |
| **Swaps** | معدلات، عملات، ائتمان |
| **Delta / Gamma / Vega** | إدارة حساسيات الخيارات |

البنوك: تسعير للعميل + تحوط المخزون + حدود مخاطر المشتقات + (في OTC) مخاطر الطرف المقابل.

## 10) التنظيم والحوكمة (لا يُتجاهل في البنوك)

أمثلة محاور (تختلف حسب السلطة القضائية):

- متطلبات رأس المال (بازل وأطر لاحقة مثل نقاشات FRTB لمخاطر السوق)  
- Volcker-type restrictions على prop في بعض الأنظمة  
- Best execution وواجبات الوسيط  
- شفافية ما بعد الصفقة، short selling rules  
- فصل المهام، سجل التدقيق، نموذج المصادقة الثلاثي أحياناً (صانع / مخاطر / امتثال)

**للمتداول الفرد:** حتى بلا بنك، مبادئ الحوكمة (حدود، سجل، فصل قرار/تنفيذ) تنقل نضج المكتب.

## 11) السلوك والأزمات

| موضوع | لماذا يُدرَّس |
|--------|----------------|
| حدود المراجحة | السوق قد تبقى «غير عقلانية» أطول من قدرة الممول |
- انهيارات سيولة | السعر موجود لكن الحجم غير قابل للتنفيذ |
| أحداث مثل Flash Crash | تفاعل خوارزميات وسيولة رفيعة |
| انحيازات سلوكية | تشرح تدفقات التجزئة؛ المؤسسات تراقبها كـ flow |

## 12) منهج دراسة مقترح (من الأساس → الأعمق)

| مرحلة | مواضيع |
|--------|--------|
| 1 | أنواع الأوامر، السبريد، العمق، الفرق بين market/limit |
| 2 | Microstructure: impact، adverse selection، صانع سوق |
| 3 | تنفيذ: VWAP/TWAP/IS ومفهوم TCA |
| 4 | مخاطر: تذبذب، ارتباط، DD، حدود، فكرة VaR/ES |

| 6 | بحث منهجي: فرضية، تكاليف، out-of-sample |
| 7 | مشتقات أساسية وتحوط |
| 8 | قراءة تقارير مخاطر/تنظيم بمستوى وعي لا حفظ مواد قانونية |

## 13) قاموس مصطلحات موسّع (اختيار)

| إنجليزي | عربي تقريبي | سطر واحد |
|---------|---------------|----------|
| Bid-ask spread | فرق العرض والطلب | تكلفة فورية تقريبية لدوران صغير |
| Slippage | انزلاق | فرق السعر المتوقع عن المنفَّذ |
| Market impact | أثر السوق | تحرّك السعر بسبب حجمك |
| Adverse selection | اختيار معاكس | الطرف الآخر أعلم |
| Inventory | مخزون | مركز غير مرغوب لصانع السوق |
| VaR | القيمة المعرّضة للمخاطر | مقياس ذيل تحت فرضيات |
| ES / CVaR | النقص المتوقع | متوسط ما وراء العتبة |
| TCA | تحليل تكلفة الصفقة | جودة التنفيذ |
| VWAP | متوسط موزون بالحجم | معيار تنفيذ شائع |
| Alpha | ألفا | عائد زائد حسب النموذج |
| Beta | بيتا | حساسية للسوق/عامل |
| Capacity | سعة الاستراتيجية | كم رأس مال قبل أن تموت الحافة |
| Drawdown | تراجع من القمة | مقياس ألم المحفظة |
| Notional | القيمة الاسمية | حجم العقد لا هامش فقط |
| Mark-to-market | تقييم سوقي | إعادة تقييم يومية للمراكز |
| Haircut | خصم ضمان | تخفيض قيمة الضمان |
| Novation / CCP | مقاصة مركزية | تقليل مخاطر الطرف في مشتقات مقاصّة |

## 14) ما ليس «أساس مؤسسة» رغم الضجيج

| شائع على السوشيال | موقف المرجع |
|-------------------|-------------|
| وعد نمط واحد يربح دائماً | المؤسسات تدير احتمالات ومحافظ وحدوداً |
| تكديس 10 مؤشرات | غير معادل لـ microstructure + risk + portfolio |
| «الذكاء الاصطناعي يغني عن التنفيذ والمخاطر» | العكس: يزيد الحاجة للحوكمة |
| نسبة فوز عالية وحدها | بلا توزيع عوائد وتكاليف وسعة بلا معنى |
| نسخ صفقة المشاهير | لا TCA ولا حدود مكتب |

## 15) خلاصة تنفيذية للفريق

أهم أعمدة ما يستخدمه المحترفون والمؤسسات فعلياً:

1. **Microstructure وتنفيذ** (كيف يتشكل السعر وتكلفة الأمر)  
2. **مخاطر وحدود** (VaR/ES/ضغط/تركيز/إيقاف)  
3. **محفظة وعوامل** (ماذا تملك من الخطر المشترك)  
4. **بحث منهجي بتكاليف** (لا إشارة بلا اختبار سعة)  
5. **حوكمة وفصل أدوار** (تداول ≠ مخاطر ≠ تسوية)  
6. **وعي تنظيمي** حسب السوق والأداة  

هذا المرجع هو **طبقة الأساسات** التي تُبنى فوقها أي مدرسة شارت أو أداة AI — لا العكس.
