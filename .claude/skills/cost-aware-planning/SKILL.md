# Cost-aware planning

1. Read the repository's short project instructions and the smallest relevant task/status entry.
2. Define the deliverable, in-scope files, exclusions, risk tier, and acceptance checks.
3. Select a model that meets the risk and correctness requirements; do not optimize price at the expense of quality.
4. Identify the actual available budget measure. If provider cost or token data is unavailable, say so and use bounded attempts/time rather than inventing a dollar estimate.
5. Break work into small independently verifiable steps. Set a warning at 50%, owner review at 70%, and safe stop at 80% of the task budget.
6. Do not start paid workflows, external services, or additional agents without the required owner authorization.
7. At each checkpoint, report remaining work, measured usage (or unavailable), test status, and a resumable next step.

Never increase the budget yourself. Never treat an estimate as an invoice.
