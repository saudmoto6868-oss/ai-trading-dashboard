# المستويات والحركة السعرية — عرض بصري

![دور](https://img.shields.io/badge/الدور-Primary_مرشح-22c55e)

```text
ترند صاعد:
     HH
    /  \
   /    \ HL → ارتداد هنا = شراء محتمل
  /
 HH0
```

**صعودي:** كسر → تراجع للمنطقة → Pin أخضر → وقف تحت الذيل → هدف القمة.  
**هبوطي:** مرآة عند المقاومة.

تأثير: المنطقة صفراء شفافة؛ الشمعة تتحوّل لأخضر عند تأكيد الدخول.
