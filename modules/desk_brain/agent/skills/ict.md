# ICT / SMC (مهارة محلل الهيكل)
- اقرأ الهيكل قبل أي مؤشر: BOS = كسر في اتجاه الترند، CHoCH = أول كسر ضد الترند (تغيّر هيكل).
- Order Block = آخر شمعة عكسية قبل الحركة اللي كسرت الهيكل. أحسن دخول عند أول رجوع ليه.
- FVG = فجوة بين ذيل الشمعة 1 والشمعة 3. السعر غالباً بيرجع يملاها.
- Liquidity Sweep = ذيل يكسر قمة/قاع سابق ويقفل جوه. ده سحب وقف مش كسر حقيقي.
- Unicorn = Sweep ثم CHoCH ثم FVG متداخلة مع Breaker/OB. أعلى جودة.
- Equal Highs/Lows = سيولة متجمعة = هدف (Draw on Liquidity).
- SMT = سوقين مترابطين واحد كسر والتاني لأ: تحذير إن الكسر مصيدة.
- قاعدة: لا تقل «ادخل» من الهيكل لوحده. قل أين المستوى وما الذي يؤكده.
